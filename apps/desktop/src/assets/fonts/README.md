# IBM Plex Sans

The desktop shell self-hosts the Latin variable font from
`@fontsource-variable/ibm-plex-sans@5.3.0`:

- Source package: https://registry.npmjs.org/@fontsource-variable/ibm-plex-sans/-/ibm-plex-sans-5.3.0.tgz
- Original file: `files/ibm-plex-sans-latin-wght-normal.woff2`.
- Checked-in filename: `ibm-plex-sans-latin-variable.woff2` (unmodified bytes).
- SHA-256: `e2291e842cf5af167122a22881a740c7f2dda7716f1e8cd76680264f4a859470`.
- Copyright: IBM Corp.; SIL Open Font License 1.1, retained in `OFL.txt`.

Vite emits the font as a local desktop asset. No external font service is used.
Chinese text uses the platform's PingFang SC / Microsoft YaHei fallback; code
previews retain the existing monospace stack. Desktop staging copies this README
and the complete license into `licenses/ibm-plex-sans/`.
